# UmsatzsteuerApp – Monorepo (Starter)

Hinweis: Dieses Monorepo beinhaltet ein altes Frontend `frontend/` und ein neues parallel angelegtes Frontend `frontend-belegpruefung/` (BelegprüfungsApp). Das alte Frontend ist weiterhin vorhanden, wird aber nicht aktiv genutzt. Das neue Frontend ist dafür gedacht, die Belegprüfungsfunktionalität zu hosten.

Lokal entwickeln (BelegprüfungsApp):

```bash
cd UmsatzsteuerApp_Monorepo_Starter
npm ci
npm run dev:belegpruefung
```
